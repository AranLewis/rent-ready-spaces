# Project Summary

**What this is:** A static content/affiliate website in the "renter-friendly small-space storage & organization" niche — buying guides and how-to articles for people who can't drill into walls (renters, students, shared housing).

**Why this niche:** Chosen for a $0-budget, zero-audience, minimal-time starting point. It's non-YMYL (not health/finance/legal advice, so lower risk and no special credentials needed to write credibly), evergreen, has genuine Amazon affiliate potential (home storage products), and the "renter-friendly / no-drill" angle is narrow enough that a brand-new site has a realistic shot at ranking for long-tail keywords, unlike broad "home organization" terms.

**How it makes money:**
1. Amazon Associates affiliate links on product mentions (commission on qualifying purchases)
2. Google AdSense display ads (revenue per impression/click once traffic exists)

**Current state:** Site scaffolded, 5 seed articles published (locally), required legal/policy pages in place, monetization wiring in place but pointing at placeholder IDs. Not yet deployed publicly, not yet monetized. See `MANUAL_STEPS.md` for what's needed to go live.

**Tech stack:** Eleventy (11ty) static site generator, plain Nunjucks/Markdown, no database, no server — deploys as static HTML to any free static host (GitHub Pages, Netlify, Vercel free tier).

**Realistic timeline:** New content/affiliate sites typically take several months of consistent publishing before meaningful search traffic and income appear. This is a long-horizon project, not a quick-money scheme — see `docs/roadmap.md`.
